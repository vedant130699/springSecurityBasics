# Spring Security Demo

This project demonstrates basic Spring Security implementation using Spring Boot.

## Features

* Form-based authentication
* Public and secured endpoints
* In-memory user configuration
* Basic authorization setup

## Endpoints

* `/public` → accessible without login
* `/private` → requires authentication
